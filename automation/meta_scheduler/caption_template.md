# Caption template (reach-oriented)

Fill the `<...>` parts. Keep any legal disclosure your content needs (affiliate, "not advice", and so on) between the call to action and the hashtags.

```
<HOOK: a question or a bold claim that matches the first 2 seconds of the video> <1-2 emojis> <promise: "here's the fix" / "read this before..."> 👇

✅ <point 1: concrete, 6-10 words>
✅ <point 2>
✅ <point 3>
✅ <point 4>

📌 SAVE this <for when ...>
📲 Send it to <the exact person who needs it>
💬 Comment "<ONE WORD>" if <relatable situation>

<Next episode teaser: "Episode N drops tomorrow at 7 AM: <title>"> 🔔

<Disclosure / disclaimer lines>

#<niche tag 1> #<niche tag 2> ... (8-10 tags, see 03-reach-playbook.md)
```

## Why this layout
- **Line 1 is the search and the hook.** It is what shows before "...more". Put the real keyword (for example "failed SIP mandate", not "episode 49") in it.
- **Save / Send / Comment** ask for the three actions that tell the algorithm a Reel is worth showing to more people.
- **Teaser** gives people a reason to follow.
- Check the **end** of the text box after typing: a long caption can drop its last hashtag.
